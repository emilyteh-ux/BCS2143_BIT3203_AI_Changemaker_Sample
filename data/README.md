# Data

`campus_map.json` is a small, fully simulated campus map used by the prototype. Coordinates,
distances and accessibility attributes are fabricated for teaching purposes and do not
represent a real institution, so no ethical clearance or anonymisation is required.

Each edge records:
- `distance` — approximate walking distance in metres
- `wheelchair_accessible` — whether the path segment can be used by a wheelchair user
- `surface` — paved / gravel_slope / stairs (used for reporting, not scoring)

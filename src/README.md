# Source Code

- `graph.py` — loads the campus map and exposes neighbour/edge lookups.
- `heuristics.py` — the straight-line-distance heuristic used by A*.
- `search.py` — the two AI methods compared in this project: Uniform Cost Search (baseline)
  and A* search with an accessibility constraint (improved method).
- `main.py` — command-line entry point that runs a route query and prints the result.
